# PureWhiteboard Design

PureWhiteboard is an Excalidraw-powered workspace for sketching, diagramming, and exporting hand-drawn whiteboards.

The app should prioritize fast drawing, shape and text creation, connectors, scene persistence, package loading, and image export. Whiteboard scene logic, package handling, paths, agent context, handlers, and catalog are app-owned.

The assistant contract should help inspect whiteboard context, add shapes and text, connect elements, remove elements, clear boards with review where appropriate, and export images.
